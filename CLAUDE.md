## Architecture

This is a **Strapi v5** headless CMS backend for a Vietnamese wedding services booking platform. It exposes a REST API at `/api/` and an admin panel at `/admin/`.

### Key directories

- `config/` — Strapi configuration modules (server, database, admin, middlewares, api)
- `config/env/production/` — Production overrides (PostgreSQL/Supabase, Render deployment URL)
- `src/api/` — Collection and single types, each containing `content-types/`, `controllers/`, `routes/`, `services/`
- `src/components/` — Reusable schema components shared across content types
- `src/index.ts` — App-level register/bootstrap hooks
- `types/generated/` — Auto-generated TypeScript definitions (do not edit manually)
- `database/migrations/` — Manual migration scripts (currently unused; Strapi manages schema via schema.json)

### Components

- `booking.booking-item` — One line-item in a booking (service/package, qty, price, subtotal)
- `booking.status-history` — Audit entry for each booking status change
- `common.banner-slide` — Homepage carousel slide

### Business logic via lifecycle hooks

All booking logic lives in `src/api/booking/content-types/booking/lifecycles.ts`:

- **beforeCreate**: Auto-generates booking code (`WB-YYYYMMDD-XXXX`, incrementing per day), calculates subtotals from items, applies discounts, sets `totalAmount` and `remainingAmount`, seeds initial status history entry.
- **beforeUpdate**: Recalculates totals when items change; appends a status-history entry when `status` changes, recording timestamp, user, and optional note.

### Database

- **Development**: SQLite (default, zero-config)
- **Production**: PostgreSQL on Supabase via `DATABASE_URL` env var; SSL with `rejectUnauthorized: false`

Copy `.env.example` to `.env` and fill in secrets before running locally. Required keys: `APP_KEYS`, `API_TOKEN_SALT`, `ADMIN_JWT_SECRET`, `TRANSFER_TOKEN_SALT`, `JWT_SECRET`, `ENCRYPTION_KEY`.

### API defaults

Configured in `config/api.ts`: `defaultLimit: 25`, `maxLimit: 100`, `withCount: true`.

### TypeScript notes

- Server-side TypeScript uses `strict: false`; admin panel (`src/admin/tsconfig.json`) uses `strict: true`
- `types/generated/` is auto-regenerated by Strapi — never edit those files
- Compiled output goes to `dist/`
